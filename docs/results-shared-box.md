# Results: shared development machine

Generated by `scripts/report.py` from the JSON lines in `results/shared-box/`. Every number below comes from a script in `scripts/` and can be reproduced with it.

Secondary results. A desktop CPU that is about twice as fast per core, so CPU-bound paths (recovery, the pipelined write path, gRPC) do better here. The NVMe was shared with other services' flushes during the runs. Primary results: [results.md](results.md).

## Host

- **cpu**: 12th Gen Intel(R) Core(TM) i7-12700H
- **cores**: 20
- **memory**: 64191404 kB
- **disk**: PC801 NVMe SK hynix 1TB
- **kernel**: 7.0.0-31-generic
- **fdatasync (4 KiB append)**: p50 2043 µs, p99 4787 µs
- **fdatasync (4 KiB overwrite)**: p50 1506 µs, p99 1714 µs
- **load average at capture**: 5.25 7.02 6.54
- **note**: shared development machine: kind clusters, etcd, Cassandra, MySQL and other sessions' builds were running and issuing their own device flushes; idle, the same 4 KiB overwrite fdatasync measures ~250 µs
- **code**: 83655ff (cluster suite: next commit, which only adds thread names)

## Reading these numbers

Every write below is acknowledged only after `fdatasync`, so most numbers scale with the device's flush latency. These runs shared the machine with other services that also flush the same NVMe, and the raw 4 KiB overwrite+fdatasync latency during the runs was ~1.5 ms, about six times what the drive does when idle. Treat the absolute throughput and latency as conservative. The comparisons (global lock vs pipelined, this engine vs RocksDB) were interleaved round by round, so both sides saw the same conditions. Recovery and failover are not flush-bound and barely move. Ranges show min–max across rounds.

## Failure testing (`scripts/bench-chaos.sh`)

16 writers against a 3-node cluster; the leader is SIGKILLed every 3 s and restarted 1 s later (every 4th cycle SIGTERM instead, which hands leadership over first). Failover = kill to the first write acknowledged by another node. Lost = keys whose final value is below the last acknowledged write; stale = linearizable reads that returned a value older than an acknowledged write.
